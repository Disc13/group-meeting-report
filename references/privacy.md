# 公开代码与私有运行材料

公开版包含通用Skill说明、处理脚本、可移植示例配置和合成测试。它从源码白名单建立独立仓库，不带本机私人版本的Git历史。

未纳入公开版的材料包括真实回放链接与短码、会议编号、字稿、报告、人物档案、PPT/PDF原件、截图、视频、OCR、缓存、Cookie、签名媒体地址、访问凭据、机器用户名和个人知识库配置。示例人物和测试日期均为虚构。标准算法测试向量不属于访问凭据。

发布前检查实际Git文件清单、文本与编码后的字符串、暂存内容、提交身份和文件类型；不要仅依赖.gitignore或只搜token关键词。公开版采用新文件默认忽略的源码白名单，运行目录和本地配置不在白名单内。不要用git add -f强行加入真实材料。

**运行得到的资料仍然是私有内容。** 分享页、接口响应、manifest和下载缓存可能带有身份信息、访问参数或签名URL；整理后的报告也可能包含未发表研究。把会议工作目录放在仓库之外，或放在默认忽略的meetings/下。不要把错误日志、终端截图或运行目录直接贴到公开Issue；先检查其中的个人信息与访问参数。

脚本中没有隐藏的付费模型调用或上传步骤。下载与字稿获取需要访问用户提供的平台；媒体、OCR、图像匹配及标注由本地脚本处理。Agent如何调用模型由宿主平台决定，不能因此宣称整套含写作的流程完全离线。

公开代码不代表允许公开会议内容，也不代替分享者对下载、转写和传播的授权。只有在用户要求且材料获准公开时，才另行准备脱敏示例。
